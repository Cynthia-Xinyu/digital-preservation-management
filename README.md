# Digital Preservation Management

A browser-based digital preservation management workflow in English, Simplified Chinese and Cantonese.

## Use

Open `index.html` in a browser, or visit the GitHub Pages site after publication. Select a project phase, add only the tasks and decision gates your project needs, record owners, deliverables, evidence and status, and export CSV or JSON.

The reference example is simulated. No project facts, rights or approvals are verified by the application. Project data is stored locally in the browser; the site does not send entries to a server. The "Copy AI brief" action copies text for use in a separate AI assistant and does not run AI in the site.

## Deployment

Publish the repository's root directory from the `main` branch with GitHub Pages. No build step is required.
